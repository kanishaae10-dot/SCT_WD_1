
# SCT_WD_1 - Responsive Landing Page

## About the Project
This project is a responsive landing page developed as Task 01
of the SkillCraft Technology Web Development Internship.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Fixed navigation bar
- Navigation color and style changes on hover
- Navbar appearance changes when scrolling
- Active navigation link highlighting
- Responsive mobile navigation menu
- Smooth scrolling between sections
- Responsive design for desktop, tablet and mobile
- Hero, Features, About and Contact sections

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. Scroll through the page and test the navigation menu.
